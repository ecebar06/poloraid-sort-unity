# First ten levels: missing icons

Generated with the built-in image tool; Python only prepares PNG files and validates them. No API key or API runner is used.

Final assets: `Assets/_Game/Resources/Icons/Generated/<spriteKey>.png`.
Import: single sprite, RGBA, 512x512, no mipmaps, bilinear, clamp, uncompressed.
Only sprite references change; level `useIcon` flags remain unchanged.

the object, clean polished game asset look, centered composition, no hard outline,
no text, no logo, no letters, no numbers, no extra props, no scene background,

the icon, NOT white background and NOT a painted checkerboard. Entire silhouette
visible with 12 percent margin. One subject only.
